# Routed execution policies

`GraphBuilder` defaults to the original double-buffered Tower composition. Each backend owns a bounded `Endpoint`, and an outer bounded `Endpoint` owns the router service. The outer worker and every backend worker retain their selected service instance through readiness and dispatch. Outer `capacity` bounds aggregate per-version execution and buffering. `GraphDraft` continues to use one bounded endpoint.

`GraphBuilder::without_outer_capacity()` selects backend-only execution. The accepted request future selects a backend on its **first poll** and executes through that endpoint directly. Unpolled or already-expired futures do not invoke the selector or submit to a backend. There is no outer worker, semaphore, queue, or aggregate per-version execution limit. Each backend's `max_in_flight` and `buffer_capacity` remain enforced, as does the runtime-wide `RuntimeLimits::max_outstanding` budget across versions and handles. Accepted unpolled futures still retain their selected publication and global slot. An explicit `capacity` conflicts with this policy in either builder call order and fails validation.

`GraphMetadata.capacity` is `Option<Capacity>`: `None` for backend-only graphs and `Some(capacity)` for buffered graphs. That field type change is a source break for consumers that previously treated it as a bare `Capacity`.

Backend-only routing improved throughput and mean latency in the measured workloads. At 200k offered requests/s it also reduced p99, while at 400k its p99 was 1.35 ms versus 1.21 ms for buffered routing. The 400k run offered 262,144 arrivals over about 0.66 seconds, so that tail difference is diagnostic rather than a stable production prediction. Worker scheduling and achieved load can differ between policies. The probe exposes worker counts, immediate and delayed services, backend skew, and open-loop offered load. Its `/proc/self/schedstat` counters describe only the thread-group leader on some Linux kernels and must not be treated as process-wide scheduling metrics.
