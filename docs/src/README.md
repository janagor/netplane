# Netplane documentation

Netplane is an early stage Rust library with bounded Tower execution, atomic version publication, request-version retention, cancellation, and graceful shutdown. This book covers the current runtime contract and development guides. Global admission budgeting is implemented; general graph construction remains future work.

- [Getting started](getting-started.md) covers local setup.
- [Architecture](architecture.md) summarizes the project contract and decisions.
- [CI/CD](ci.md) describes the current automation.

For repository onboarding, use the [README](https://github.com/janagor/netplane/blob/main/README.md), [QUICKSTART](https://github.com/janagor/netplane/blob/main/QUICKSTART.md), and [AGENTS](https://github.com/janagor/netplane/blob/main/AGENTS.md) files.
